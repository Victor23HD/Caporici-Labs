## Consenso (o que vamos construir)

**Mundo:** terminal fosforescente à meia-noite × minimalismo exagerado.

- Página = CRT/terminal, não um card de aeroporto.
- Display enorme (clamp até ~6rem), peso alto, tracking negativo controlado.
- Paleta: quase-preto + phosphor green + amber cursor/hold + soft green “OK”.
- Um momento de motion: cursor que respira + linhas que “bloom” ao entrar.
- Home Persuade; docs Read (mesma tipografia, menos ruído, medida ~68ch).
- Ferramenta Operate: inputs como prompt, saída como dump mono.
- Sem eyebrow, sem gradient text, sem card-grid de ícones, sem purple SaaS.
